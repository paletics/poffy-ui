# Components

This folder contains the components shipped by `@poffy-ui/react`.

If you are looking for product-tier add-ons (Pro/Enterprise), they are intentionally **not** part of this repository.

## Inventory

### a11y

- `VisuallyHidden`

### animations

- `ActionMotion`, `CollapseTransition`, `ContentTransition`, `DragMotion`
- `IconSwapTransition`, `LayoutTransition`, `ListTransition`, `LoopEffect`
- `NumberTransition`, `OverlayTransition`, `PathDrawTransition`, `ReorderTransition`
- `RevealTransition`, `SelectionTransition`, `StaggerTransition`, `TextRevealTransition`

### data-display

- `Avatar`, `AvatarGroup`, `Badge`, `DiffViewer`, `List`, `Reference`, `Stat`, `Table`, `Tag`

### feedback
