# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub Issue for security reports.

Instead, use GitHub's private reporting channel:

- Go to the repository page -> **Security** -> **Advisories** -> **Report a vulnerability**

Include as much of the following as possible:

- A clear description of the issue and its impact
- Steps to reproduce (PoC code is welcome if safe)
- Affected package(s) and versions (`@poffy-ui/react`, `@poffy-ui/system`, etc.)
- Any suggested fix or mitigation

## Supported Versions

We generally support the latest released version of each package. If you are unsure, report anyway.

## Disclosure

We will coordinate a fix and release before public disclosure when possible. We do not currently run a bug bounty program.
